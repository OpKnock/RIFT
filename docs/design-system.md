# RIFT Design System

RIFT should feel like a scientific control room, not a generic AI chat app.

## Visual language
- Dark-first
- High information density without clutter
- Monospace for measurements and formulas
- Strong experiment-state hierarchy
- Motion only for live simulation transitions

## Core surfaces
World State, Future Lattice, CHAOS Findings, Optimization, GUARDIAN, and Benchmarking.

## Rule
Every visualization must correspond to an actual model output. Decorative AI effects must never imply scientific validity.
